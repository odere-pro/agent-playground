## How the work was run

One orchestrator judged; Opus 5.5 subagents built the larger and security-sensitive tasks, Sonnet 5.5 the small ones. Lessons that held:
- One agent at a time on Docker or kind.
- Each agent owns named files; a shared brief lists the seams and rules.
- Run pytest over earlier PoCs only through `scripts/check_offline.sh` or `-m "not network"`; plain `uv run pytest` starts Docker.
- Long writes get cut off: append one section per write; have agents write long reports to a notes file.
- Turn limits: developer and tester about 60; resume with SendMessage, not a new agent.
- A read-only code review and a security review after each wave found real bugs both times. Keep them.
- Refer to security checks by their H ids; describe them as "the control refuses X", never as how to do X.

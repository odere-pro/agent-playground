# PoC-2 open: design decisions (2026-10-01)

Taken when PoC-2 opened, so a later session does not re-derive them. Values the planning docs do not give are marked `suggested:`.

## Workload folders

- The two new workloads follow the existing naming. `packages/workloads/echo-pydanticai` (module `echo_pydanticai`) and `packages/workloads/echo-langgraph` (module `echo_langgraph`) join `echo-python` and `echo-typescript`.
- "echo" is the repo's name for the simplifier plug-in (`agent: echo`). It is the same business logic in every framework.

## The template A2A server for Python workloads

- It lives in a new workspace package, `packages/workload-a2a` (module `workload_a2a`).
- It is a copy of `chassis.adapters.a2a.mapping` and `chassis.adapters.a2a.server`. One change: `parse_event` is replaced by `jsonschema` validation against a vendored `events.v0.json`.
- It never imports `chassis`. The import-linter contract "a workload never imports the chassis (ADR-002)" now covers it.
- A test diffs its `mapping.py` against the chassis copy, as contract v0 suggests.
- This is ADR-002's "`a2a_server.py` in the workload container", as one shared package instead of three copies. suggested: to be confirmed by `chassis-architect` when contract v1 is written.

## The `sidecar` lane in the offline gate

- The gate runs pytest with `--disable-socket --allow-unix-socket`.
- So in the gate the `sidecar` lane is tested over a Unix domain socket (uvicorn `uds=`, httpx `uds=`). That is a real socket, real server-sent events, and a separate server task.
- Over TCP on `127.0.0.1` it runs only under the `network` marker and in the Compose demo.
- The connector takes `spec.engine.url` (localhost only). For tests it also takes a `uds` path.

## Two listeners on the chassis

- The model proxy and the MCP tool endpoint move to a second listener, bound to localhost only. suggested: port 8090.
- The public port keeps `/v1/run`, `/health`, and `/ready`.
- This pays the PoC-1 debt in `pocs/poc-01-walking-skeleton/notes/2026-09-29-inprocess-debt.md` ("The model proxy sits on the public port").

## The tool

- `glossary_lookup` is defined once, in the chassis's fake `ToolPort`.
- The chassis serves it over MCP (FastMCP 4, streamable HTTP).
- Every workload is an MCP client of the chassis.

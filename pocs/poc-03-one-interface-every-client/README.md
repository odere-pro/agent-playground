# PoC-3: One interface for every client: OpenAI, Anthropic, and MCP on every engine

This iteration puts OpenAI, Anthropic, and MCP interfaces on the chassis, next to native `/v1/run`.
It exists so any client can call any engine the same way, with only a base URL change.
Run its offline gate with `make test-poc POC=03`.

Status: done (2026-10-01)
Planning doc: [003-PoC-3-one-interface-every-client.md](../../docs/planning/poc/003-PoC-3-one-interface-every-client.md)
Time box: 1 week
Builds on: [PoC-2](../poc-02-two-engines-one-contract/README.md) (the `handle` contract, the echo engines, the `inprocess` and `sidecar` lanes)
Hands to: [PoC-4](../poc-04-stateless-scalable/README.md) (idempotency and client disconnect on every interface, contract v3), [PoC-6a](../poc-06a-bake-off-sidecar-lane/README.md) (the bake-off calls engines through these interfaces), and [PoC-8](../poc-08-cross-cutting-build/README.md) (caller identity on the MCP hop)

## Question

Can any client call any engine the same way, through native, OpenAI, Anthropic, and MCP interfaces?

## How to run

```bash
make test-poc POC=03         # the offline gate for this iteration
make record-cassettes        # re-record the model cassettes, offline, against the fake model server
```

The TypeScript cells need `npm ci` in `packages/workloads/echo-typescript` once; without `node_modules` they skip.

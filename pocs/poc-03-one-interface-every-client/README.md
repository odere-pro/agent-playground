# PoC-3: One interface for every client: OpenAI, Anthropic, and MCP on every engine

Status: not started
Planning doc: [003-PoC-3-one-interface-every-client.md](../../docs/planning/poc/003-PoC-3-one-interface-every-client.md)
Time box: 1 week

## Question

Can any client call any engine the same way, through native, OpenAI, Anthropic, and MCP interfaces?

## Scope

- [ ] `POST /v1/chat/completions` (OpenAI-compatible) in the chassis, streaming and complete.
- [ ] `POST /v1/messages` (Anthropic-compatible) as an inbound adapter in the chassis, using the official `anthropic` SDK types.
- [ ] An inbound contract suite: the same logical request through every adapter gives the same canonical request, and maps back correctly.
- [ ] The OpenAPI 3.1 spec generated by FastAPI.
- [ ] MCP tools generated from the OpenAPI spec with FastMCP 4 (`from_fastapi`, curated route maps), mounted in the app, with LiteLLM's MCP gateway in front.
- [ ] `GET /manifest`: a first version, built from the config and the OpenAPI spec.
- [ ] An interface contract suite that covers both lanes: every interface × every engine × streaming and complete × both transports (over A2A on localhost in the `sidecar` lane, and over A2A in memory in `inprocess`).
- [ ] Record-and-replay fixtures (vcrpy or pytest-recording) for model calls, so the contract tests run without a live model.
- [ ] Schemathesis property tests generated from the OpenAPI spec.

## Exit criteria

Each one has a scenario test in `tests/` or a recorded reason it cannot have one yet.

- [ ] The interface contract suite and the Schemathesis tests run offline in CI on every commit.
- [ ] The contract suite passes for all engines and all interfaces, over both transports.
- [ ] The OpenAI and Anthropic SDKs work with only a base URL change.
- [ ] An MCP client lists the agent's tool and runs it.
- [ ] The MCP tools and the REST API come from the same OpenAPI spec (no hand-written tool definitions).
- [ ] Any gaps between the formats are listed (for example tool calls or stop reasons that do not map one to one), with how each is handled.

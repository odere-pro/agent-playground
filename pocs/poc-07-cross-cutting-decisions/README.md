## Question

Does the chosen stack give security, observability, feedback, and evals to every engine, in every lane, added once at the chassis and LiteLLM, with no engine-specific code?

## Scope

## How to run

Offline, with no socket and no key (`105 passed, 8 skipped` on 2026-10-28; the 8 skips are the stack drills):

```bash
make test-poc POC=07
scripts/check_offline.sh pocs/poc-07-cross-cutting-decisions -q -rA   # the same, with every test name
uv run python -m chassis_contracts.redteam                            # the red-team set, both stacks
uv run python -m bakeoff.evaltrial --tool deepeval --out "$OUT"       # the picked eval tool on two engines
```

With Docker (CI runs it in `poc07-stack.yml`):

```bash
deploy/compose/poc07/stack.sh up && deploy/compose/poc07/stack.sh wait
POC07_STACK=1 uv run pytest pocs/poc-07-cross-cutting-decisions/tests/test_poc07_stack.py -q
deploy/compose/poc07/stack.sh down
```

The agent scan: `deploy/agent-scan/scan.sh` (needs Docker; the `scan` half needs `SNYK_TOKEN`). CI runs it in `poc07-agent-scan.yml`.

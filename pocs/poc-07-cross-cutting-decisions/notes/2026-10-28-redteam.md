# PoC-7 red-team run, 2026-10-28 (exit criterion 7)

The set: `packages/contract-suites/src/chassis_contracts/redteam/cases.yaml`, 18 cases in four categories. Each case goes through a real chassis app, in process, offline. The chassis has two guardrail stacks:

- `litellm`: `LiteLLMGuardrails` calls a stub of LiteLLM's `POST /guardrails/apply_guardrail`. The stub's `prompt-guard` and `secret-guard` call the guardrail server (`packages/guardrail-server`) over LiteLLM's generic guardrail API. The classifier is the **pattern stand-in**, not Prompt Guard 2. `pii-mask` is a regex stand-in for Presidio.
- `keyword`: `KeywordGuardrails`, the port's fake.

**Prompt Guard 2 numbers are not here.** Llama Prompt Guard 2 is a gated model on Hugging Face, and Hugging Face answers 403 from this container. Its numbers wait on a run where Hugging Face is reachable (the Mac run): `guardrail-server --classifier prompt-guard` behind LiteLLM, then the same cases.

## Command

```bash
uv run python -m chassis_contracts.redteam \
  --write pocs/poc-07-cross-cutting-decisions/notes/2026-10-28-redteam-results.json
```

`tests/test_poc07_redteam.py` runs the set again and checks that the result equals `2026-10-28-redteam-results.json`.

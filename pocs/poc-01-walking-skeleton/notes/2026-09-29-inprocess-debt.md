# `inprocess` lane and model proxy: debt (2026-09-29)

Recorded from the PoC-1 review. Each item names the iteration that pays it.

- **Events arrive after `handle` returns.** `httpx.ASGITransport` runs the whole app call before it returns the body, so in the `inprocess` lane the connector sees the events in one batch: no per-delta streaming, `budget.timeout_ms` never fires mid-run, and `CancelTaskRequest` never lands mid-run. Written into `docs/contracts/contract-v0.md` ("`EngineConnector`, draft" and "Versions and cancel"). The `sidecar` lane in PoC-2 streams over a socket; a streaming ASGI bridge is PoC-2 work if the in-memory lane must stream. The connector's cancel path is exercised by `packages/chassis/tests/test_a2a.py::test_cancel_while_the_handle_is_mid_await_is_clean` at the executor level only; a timeout test cannot be made deterministic in this lane and is not written.
- **No `traceparent` header.** The `inprocess` connector sets no HTTP header; `ctx.trace_id` carries the trace. The contract doc marks the header as PoC-2.
- **`InMemoryTaskStore` is never pruned.** a2a-sdk 1.2's `DefaultRequestHandler` owns the store and saves the task after the terminal update through its `TaskManager`; it never calls `TaskStore.delete`, and the executor holds neither the store nor a `ServerCallContext`, so a delete from `HandleExecutor` would race the handler's own save. Every task stays in memory for the life of the process. Deadline: PoC-2, with the sidecar server (a delete after the terminal update in the request handler, or a bounded store).
- **The model proxy sits on the public port.** `chassis.server.model_proxy` is mounted on the same app as `/v1/run`, and `deploy/compose/docker-compose.yaml` publishes that app on `127.0.0.1:8080`. `deploy/CLAUDE.md` says the proxies are localhost-only and the public port binds to the pod IP. In PoC-1 anything on the host that reaches 8080 can spend with the chassis key. PoC-2 splits the public port from the proxies: the proxies move to a localhost-only listener the sidecar reaches, and the public port carries `/v1/run`, `/health`, `/ready` only.

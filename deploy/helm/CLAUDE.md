# deploy/helm

The shared library chart (backlog 024 CH-3) and one example chart that includes it. `deploy/CLAUDE.md` still applies. Ask `platform-security` before changing anything that touches a Secret, a NetworkPolicy, the RuntimeClass, or a security context.

- `agent-lib/` is `type: library`: named templates only, in `templates/_*.tpl`. It renders nothing on its own.
- The chassis image tag is set once, in `agent-lib.defaults` (`templates/_values.tpl`). A service pins the previous tag with one value, `chassis.image.tag`. Never `latest`.
- Secrets go to the chassis container only, through `chassis.secretEnv`, `chassis.envFromSecrets`, or `chassis.secretVolumes`. The workload has an allow-list of keys and plain env only; `templates/_validate.tpl` fails the render otherwise. Do not add a workload key that can carry a Secret, a volume, or a security context.
- The uids are not values: chassis 10001, workload 10002 (the uid table in `deploy/README.md`).
- The lane and the trust level come from the chassis config (`chassis.config.spec.engine.connector`, `chassis.config.spec.trust`). `untrusted` needs `remote`. The remote lane is two pods; the workload pod runs under gVisor with its own token only, the Secret `<name>-workload-token` the chart names (ADR-005).
- Egress is default deny (026 CH-4): peers by namespace and pod labels with ports, no `ipBlock`, no rule without a `to`, no empty selector, and `<name>-default-deny` per namespace. Do not add a value that drops a policy type or a peer check.
- The admission rules are the platform's: `agent-lib.admission` (`templates/_admission.tpl`), installed through `agent-admission/`, never included by a service chart. Two policies: `agent-trust-rule` (rules 0 to 8) is `deploy/kind/poc05/admission/policy.yaml`'s spec and `agent-chassis-version` (rule 9, the minimum chassis version) is `chassis-version-policy.yaml`'s, the same parsed specs, and `test_poc09_chart_boundary.py` holds them equal: change the CEL in the PoC-5 file first (its static test, pins, fixtures, and model), then copy it here. Rule 9 stands alone so its binding can warn first (`admission.chassisVersionAction`, `Deny` or `Warn`, ADR-001 item 9); the trust rule's binding always denies. The chassis tags it allows are `chassis.image.supportedTags` in `_values.tpl`, the library's, bumped with the tag.
- No secret value in any file here. Secrets are made outside the chart.
- Test: `make test-poc POC=09` runs `pocs/poc-09-agent-mvp-template/tests/test_poc09_chart.py` (criterion 5) and `test_poc09_chart_boundary.py` (admission and default-deny egress), on the `chart` fixture from `chart_render.py`. They skip with a reason when `helm` is not on PATH; `.github/workflows/poc09-helm.yml` installs a pinned helm and runs them. A refusal test never changes to pass; fix the chart.
- A service chart's `templates/` files are `<object>.tpl` with no leading underscore: Helm renders every file there not named `_*` as a manifest, and the `.tpl` suffix keeps raw Go templates out of the repo's `deploy/**/*.y*ml` scans (`test_poc06b_kind_static.py`).
- Do not: install helm globally, commit `charts/` or `Chart.lock`, or edit a rendered manifest by hand.

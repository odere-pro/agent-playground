# Planning sync

Read `docs/planning/CLAUDE.md` first. In short:

- The epic `slm-agent-platform-epic-v3.md` is never edited. `make planning-check` fails if its checksum changes.
- Hand-written: issue bodies (`## Why`, `## What`, `## Out of scope`, `## Acceptance criteria`), everything in `poc/` and `adr/`.
- Generated by `make planning-sync`: frontmatter, `## Reuse`, `## Dependencies`, `## References`, file names, `NNN ID` references, and `issues/000-plan.md` (from `tools/plan-template.md`).
- To reorder, resize, or change dependencies: edit `ROWS` in `tools/backlog.py`. To change `## Reuse`: `tools/reuse_map.py`. To change the plan prose: `tools/plan-template.md`.
- To add an issue: add a row to `ROWS`, run `make planning-sync`, replace the `<!-- BODY -->` marker, run `make planning-check`.
- Acceptance criteria never depend on a higher-numbered issue. A later issue that extends the scope is named under `## Out of scope`.
- Values the epic does not give are marked `suggested:`.

Always finish with `make planning-sync planning-check` and paste the last line of each.

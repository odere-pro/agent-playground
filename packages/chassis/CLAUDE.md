# packages/chassis

The service chassis. Day 0 holds the contract and the fakes; the walking skeleton adds the server; PoC-3 adds the public interfaces; PoC-4 adds state, events, the config store and reload, idempotency, readiness, and the drain. Spec: `docs/contracts/contract-v3.md` (PoC-4's additive changes; v2 and v1 for what v3 does not name). How PoC-4 works: `docs/guides/poc-04-how-it-works.md`.

## Layout

- `core/` `trace.py` (`trace_id_hex`, `traceparent_for`: the W3C `traceparent` from `ctx.trace_id` and the run span; `parse_traceparent`, the inbound header's trace id, shared by the model proxy and the MCP adapter; stdlib only), envelope (`Request`, `Response`, `Context` with the optional `traceparent`, `TaskInput`, `Versions`), events (`Start`, `Delta`, `ToolCall`, `Metrics`, `End`, `Error`), `collect()`, the `Handle` type and `echo`, `inbound.py` (the inbound adapter seam: `Ids`, `Served`, `ReplyMeta` with `for_request` and `collect`, `Reply`, `StreamReply`, `Refused`, the `InboundAdapter[BodyT]` Protocol with the pure `to_request` and the back-mapping `complete`, `stream`, `error`, `Interface`, `status_for(code, retryable)`, the PoC-3 status table with 500 for `engine_error` and `internal_error`, plus PoC-4's 422 `idempotency_conflict`, 409 `idempotency_in_progress`, 503 `state_unavailable`; `PUBLIC_MESSAGES` and `public_message(code)`, the fixed client-facing error text, suggested; `answer_text`, the answer a chat format shows, and `rest_of_answer`, what a stream sends after its deltas), `manifest.py` (`Manifest` v0: `ManifestAgent`, `HttpInterface`, `McpInterface`, `OpenAPIRef`; suggested: the whole shape), `results.py` (`TaskResult`, the result-event payload; `TASK_COMPLETED` `agents.task.completed.v1`, `TASK_FAILED` `agents.task.failed.v1`). No network, no product SDK, no web framework. `make lint` enforces it.
- `ports/` one `typing.Protocol` per dependency: `ModelPort`, `EngineConnector`, `ConfigPort`, `TelemetryPort`, `ToolPort` (`ToolDefinition` with a JSON Schema `parameters`, `ToolResult`, `ToolError` with `unknown_tool` or `bad_arguments`), `StatePort` (`state.py`: bytes by key, `get`, `set`, `set_if_absent` with a required TTL, `compare_and_set` (`value=None` deletes), `delete`; every failure is `StateUnavailable`; `InMemoryState` lives here because the bundle defaults to it), `EventPort` (`events.py`: `publish`, `subscribe(topic, handler, *, group, max_attempts)`, `CloudEvent` (CloudEvents 1.0 structured JSON, extensions `traceparent`, `idempotencykey`, `configversion`, `modelroute`, `partitionkey`), `PublishFailed`, `DLQ_SUFFIX` `.dlq`, `NoEvents`), `ConfigUnavailable` in `config.py`, `EngineConnector.probe()`; bundled in `PortBundle` (`tools` defaults to `NoTools`, `state` to `InMemoryState`, `events` to `NoEvents`). New ports arrive with their first adapter (see `profiles.REGISTRY` for which PoC).
- `fakes/` in-memory doubles: `ScriptedModel`, `FakeEngine`, `InMemoryConfig`, `InMemoryTelemetry`, `InMemoryTools`, `InMemoryState` (re-exported), `InMemoryBus` (`events.py`: at least once, retries in place, then `<topic>.dlq`; `published`, `fail_next_publish`; two replicas in a test share one). `FakeEngine` is a test double, not a lane. `fakes/tool.py` defines the shared read-only `glossary_lookup` once (`GLOSSARY`, `default_tools()`); arguments are checked by a small hand-written JSON Schema check, not `jsonschema`.
- `adapters/` real adapters, one package per product; the product SDK is imported only there. `litellm/` is `LiteLLMModel`: `ModelPort` over OpenAI-compatible HTTP with httpx, built by `LiteLLMModel.from_env()` from `LITELLM_BASE_URL` and `LITELLM_API_KEY`; the key is never logged; the httpx client ignores the environment (`trust_env=False`). It binds the same contract suite as `ScriptedModel` in `tests/test_contracts.py`, offline, against the fake model server. PoC-4 adapters, each built by `from_env()` and loaded lazily: `valkey/` (`ValkeyState`: valkey-py, `VALKEY_URL`, `VALKEY_USERNAME`, `VALKEY_PASSWORD`; `compare_and_set` is one Lua script; errors become `StateUnavailable` with the class name only), `s3/` (`S3Config`, registered as `minio` and `s3`: the minio SDK in `asyncio.to_thread`, `CONFIG_S3_*`, reads `<prefix><name>.yaml`, `subscribe` polls `stat_object` every `CONFIG_POLL_INTERVAL_S` (suggested 5, ±10% jitter); a failed poll is counted, never raised), `kafka/` (`KafkaEvents`: aiokafka, `KAFKA_BOOTSTRAP_SERVERS`, `acks=all`, 3 publish attempts, commit after the handler or the dead-letter publish), `dapr/` (`DaprEvents`: httpx to daprd, no SDK; `DAPR_API_TOKEN`, `APP_API_TOKEN`; `inbound_routes()` (`/dapr/subscribe`, `/dapr/events/{topic}`) mounted on the proxy app only; retries and the dead-letter topic are Dapr's). `a2a/` is the A2A lane (a2a-sdk 1.2, imported only here): `mapping.py` (events to A2A updates and back, pure, no chassis import; `chassis.event`, `chassis.ctx`, and `chassis.input` cross as JSON strings, the v0 `Struct` form is still read), `server.py` (`HandleExecutor`, `PruningRequestHandler`, `build_agent_card`, `build_app`: the template server around a wire-form `handle`; input from `chassis.input` as is, parts only as a fallback; a bad `chassis.ctx` or `chassis.input` is `a2a.bad_request`; `cancel` only sets a flag, and `execute` closes the generator in its own task), `connector.py` (`A2AConnector`: the client side every lane shares: mapping back to events, one `traceparent` per run as the header on every request and in `ctx.traceparent`, `budget.timeout_ms` as both the per-read timeout and a whole-run deadline in every lane (`a2a.timeout`, retryable), a transport failure or a stream with no `end` or `error` as `a2a.transport`, cancel even when closing the stream raises, one span per run), `inprocess.py` (`InProcessConnector`: that server in this process over `httpx.ASGITransport`; events arrive in one batch, and the run deadline ends the stream but not `handle`), `sidecar.py` (`SidecarConnector`: the workload's own server at a loopback `spec.engine.url`, over TCP or the `spec.engine.uds` Unix socket; streams; `probe()` GETs the agent card, `InProcessConnector.probe()` is `True`). `packages/workload-a2a` holds the workload-side copies of `mapping.py` (byte for byte) and `server.py` (mirrored). `mcp/` is FastMCP 4, imported only here: `server.py` serves `ToolPort` (`build_mcp_server` adds one `PortTool` per definition with the definition's own schema, one `chassis.tool.call` span per call (`tool`, the parsed `trace_id`, and `request_id` when the run is in flight; nothing charged), `chassis.tool_calls` per tool, and a `ToolError` as an MCP tool error); `agent.py` is the agent as one MCP tool (`build_agent_mcp`: `FastMCP.from_openapi` over the `/v1/run` operation's spec, route maps keep only `POST /v1/run`, the tool is named after the agent; the inner call goes over `httpx2.ASGITransport(app)`, and `_run_headers` keeps only `FORWARDED_HEADERS` (`traceparent`, `tracestate`, `Idempotency-Key`) and sets `x-chassis-interface: mcp`). `openai_compat/` is the OpenAI chat wire format, not a client: `types.py` (the SDK types, plus `OpenAIError` with `retryable`), `inbound.py` (`OpenAIInbound`), `messages.py` (`UnsupportedMessage`, `is_empty`, `refuse_extra`, `text_of`, `tool_calls_of`, `to_port_message`), shared by the model proxy and the OpenAI interface. `anthropic_compat/` is the Anthropic Messages format: `types.py` (the anthropic 1.11 types), `inbound.py` (`AnthropicInbound`). `openai` and `anthropic` are imported only under `adapters` (`make lint`).
- `server/` `config.py` (`ChassisConfig`, `load_config`; `spec.interfaces` `{openai, anthropic, mcp}`, each on by default, unknown keys refused; `spec.limits` `LimitsSpec`: `max_tokens_max`, `timeout_ms_max`, `messages_max`, `body_bytes_max`, each at least 1; `spec.idempotency` `IdempotencySpec` (`enabled`, `ttl_s`, `lease_s`, `wait_poll_ms`, `max_entry_bytes`), `spec.events` `EventsSpec` (`result_events`; a non-null `consume` is refused at load until event-triggered runs exist); `RELOADABLE` and `RESTART_ONLY`, the field paths a reload may and may not change; suggested: every default), `config_loader.py` (`ConfigReloader`: the bootstrap file, then with a real config adapter the store document `agents/<agent.name>.yaml`; `start` fails on an invalid document, naming field paths only; `on_change` swaps `state.config` in one assignment or refuses with `invalid` or `restart_required` and keeps the last good; `chassis.config.reloaded`, `chassis.config.rejected{reason}`; a store document's version is `<version>+<hash12>`, or `<hash12>`), `idempotency.py` (`Idempotency.begin` returns `Claim`, `Replay`, or `Refusal`; the claim is a lease renewed every `lease_s / 3` and fenced on the replica's clock at `FENCE_FRACTION` 0.8 of `lease_s` without a good renew; a lost claim runs `Claim.on_lost` and never writes; a takeover after a wait gets `Claim.timeout_ms`, the budget left (at least `MIN_RUN_MS` 500); `Claim.finish` caches only a run that ended with `end`, stores a `too_large` marker over `max_entry_bytes`, else frees the key; an entry of another version or a `too_large` marker is a final 409; `store_key` `chassis:idem:v1:<agent>:<sha256>`, `fingerprint` of `{agent, input, context_ref}`), `readiness.py` (`ReadinessMonitor`, `ProbeSettings(interval_s=2.0, timeout_s=1.0, failures=3)`, `not_ready_reason`: `starting`, `draining`, `workload_unreachable`), `lifecycle.py` (`QuietServer` leaves signals alone, `CloseWhenDraining`: a pure ASGI middleware on the public app only that adds `Connection: close` to every response while `draining`, so the delay must exceed endpoint removal plus the clients' idle keep-alive window, `Drain`: SIGTERM sets `draining`, sleeps the delay, closes the public listener, waits for in-flight runs, then the proxy listener last; a second signal forces exit), `results.py` (`ResultPublisher` on `pipeline.on_finished` when `spec.events.result_events`: a background publish, never awaited by the request; `id` is `event_id(request_id, type)`, a uuid5; the key fields hold `key_hash(key)`, never the raw key; `chassis.events.published`, `.publish_failed`, `.publish_abandoned`; shutdown waits up to `SHUTDOWN_WAIT_S` 5), `app.py` (the public app: `/health`, `/ready` with `reason`, `/manifest`, then `mount_interfaces` last; each run holds a `RunRecord` in `app.state.runs`; the lifespan builds the ports, starts the reloader and the readiness monitor, and adds the result publisher; `create_app(..., probe=)`), `manifest.py` (`build_manifest`, `mount_manifest`, `spec_sha256`: `GET /manifest` built per request from the config, the OpenAPI spec, and the agent tool), `pipeline.py` (`RunPipeline` at `app.state.pipeline`, the run every inbound adapter shares: `served`, `to_request`, `open(request, *, interface="native")` (raises `TraceIdInUse`, counted and logged), `Run.events()` in one `chassis.run` span with an engine exception as one `engine_error` event, `chassis.requests` and the span labeled `interface`, `Run.response()`, `Run.complete()`, an idempotent `Run.close()`, and `RunStream` (optional `headers`, `on_close`), which frees the trace id even when the body is never iterated; `Run.seen`, `Run.done`, and `on_finished`, async callbacks awaited once after each run, never for a replay), `interfaces/` (the public interfaces over the pipeline: `mount_interfaces(app, config)` installs the body cap and the validation format, mounts native always, then the ones `spec.interfaces` leaves on, MCP last; `ids.py` (`resolve_ids`: body, then `traceparent` and the `Idempotency-Key` header, else minted; `key_from` `header`, `body`, or `minted`, and only a sent key reaches idempotency; `may_remint`; `open_run` re-mints a trace id in use once, `chassis.trace_id_reminted{interface}`, except a native body `trace_id`, which keeps its 409); `hold.py` (`hold`, `Held`: the hold rule, the run read in a task of its own so its span stays in one context); `serve.py` (`serve`: one call over an `InboundAdapter`, `enforce_limits` after `to_request`, then `Idempotency.begin` before `open_run`: a refusal through `adapter.error`, a lost claim cancels the run (`_fenced`) and answers 409 `idempotency_in_progress` with no `on_finished`, a replay with `Idempotent-Replayed: true` (`REPLAYED_HEADER`) and no run; in complete mode a watcher polls `disconnected` every `DISCONNECT_POLL_S` 0.25 and cancels the run of a client that left; `chassis.inbound_ignored{interface, param}`; a chassis failure after the run opened closes the run, logs it, and answers 500 `internal_error`, `x-should-retry: false`; `SSE_EVENT_SCHEMA`); `errors.py` (`INTERFACE_KEY` `x-chassis-interface`, `register_validation_format`: a `RequestValidationError` is 400 in the route's format, native keeps 422); `limits.py` (`enforce_limits`: 400 `limit_exceeded` over a `spec.limits` ceiling, refused, never clamped; `BodyLimit`, a pure ASGI middleware: 413 over the live `body_bytes_max` before parsing); `native.py` (strict `RunRequest`, `NativeInbound`, `describe_run`, `POST /v1/run` with `operation_id` `run` and its declared 400, 409, 413, 503); `openai.py` (the OpenAI interface (public port), `operation_id` `chat_completions`; `model` is the agent's name); `anthropic.py` (`POST /v1/messages`, `operation_id` `messages`); `mcp.py` (`/v1/mcp` on the public port, the agent as a tool: `run_operation_spec`, `mount_agent_mcp`; streamable HTTP built in the public app's lifespan, 503 before and after)), `proxy_app.py` (`create_proxy_app(public_app)`: the localhost-only proxy app, sharing the public app's `state`, no lifespan of its own; it mounts `ports.events.inbound_routes()` when the events adapter has them), `model_proxy.py` (the model proxy (proxy port): the OpenAI-compatible pass-through a workload calls, `model` is the LiteLLM route, mapped onto `ports.model` with `adapters/openai_compat/messages`; never forwards `Authorization`; keyed to its run by `traceparent`, one `chassis.model.call` span per call; a correlated call's `max_tokens` is capped at the run's remainder (the remainder when unset), reserved at start and settled on usage; 429 `budget_exhausted` when nothing is left, `retryable` only when in-flight reservations hold the rest; uncorrelated calls served with their own `max_tokens` and counted), `correlation.py` (`RunRegistry`, at most one in-flight run per trace id, `TraceIdInUse`; `RunRecord` with `reserve`, `settle`, `release`; re-exports `parse_traceparent`), `cli.py` (`chassis serve`: the public listener on `--port` 8080 and the proxy on `--proxy-host 127.0.0.1 --proxy-port 8090`, suggested; a non-loopback proxy host is refused unless `--allow-any-proxy-host`; `--drain-delay-s` 5 and `--drain-timeout-s` 30, suggested; runs both servers through `lifecycle.Drain`), `tool_endpoint.py` (`mount_tool_endpoint(proxy, lifespan_app=public_app)`: `/mcp` on the proxy port, the tools for workloads, never on the public port; streamable HTTP, built from `state.ports.tools` in the public app's lifespan; 503 before it).
- `profiles.py` `spec.adapters`, the `fake`/`local`/`cloud` profiles, `build_ports`, `check_lane`. The lane is `spec.engine.connector` (default `sidecar`); `spec.adapters.engine` is refused. `connector: inprocess` builds `InProcessConnector` (`spec.engine.handle` names the workload as `module:attribute`); `connector: sidecar` builds `SidecarConnector` (`spec.engine.url`, optional `spec.engine.uds`). `spec.adapters` (`model`, `config`, `telemetry`, `tools`, `state`, `events`) merges over the profile defaults per field; `cloud` refuses `fake` and `memory` adapters (suggested). `state`: `memory` or `valkey` (default `memory` in `fake`, `valkey` in `local` and `cloud`); `events`: `none`, `memory`, `kafka`, or `dapr` (default `none` everywhere); `config` adds `minio` and `s3`. Every PoC-4 `REGISTRY` entry is a `lazy` factory that imports its adapter inside the function, so an unused SDK (valkey, aiokafka, minio) is never loaded.
- `configs/` `fake.yaml` (the simplifier `echo_python:handle` in the `inprocess` lane, scripted model), `local.yaml`, and `sidecar.yaml` (`local` in the `sidecar` lane at `http://127.0.0.1:9000`; both pin `config: memory` and `state: memory`, so the PoC-1 to PoC-3 stacks need no store). `scale.yaml` (the Compose scale stack: `config: minio`, `state: valkey`, `events: none`), `scale-kafka.yaml` and `scale-dapr.yaml` (the same plus `result_events: true`), `scale-inprocess.yaml` (`echo_python` in the chassis, for the hop measurement).
- `schemas.py` and `schemas/*.json` the published JSON Schemas (`request`, `response`, `context`, `task_input`, `events`, `manifest`, `chassis-config`, all v0; `task-result` v1, the result-event payload), generated by `make schemas`; a test fails on drift.

## Rules

- A change to an event or envelope field is a contract change: ask `chassis-architect`, bump `schema_version` on a breaking change, keep the previous major accepted, run `make schemas`.
- Every new port gets a fake and a suite in `packages/contract-suites` in the same change (skill `contract-suite`).
- `inprocess` is for the chassis's own tests and local runs. `check_lane` refuses it elsewhere.
- Two chat routes share a path; never write it bare. Say "the OpenAI interface (public port)" or "the model proxy (proxy port)". `/v1/mcp` on the public port is the agent as a tool; `/mcp` on the proxy port is the tools for workloads.
- OpenAI and Anthropic errors send `public_message(code)`, never the run's own message; the detail stays in the log and the span.
- A replica keeps nothing a retry needs. What must outlive a call goes behind `StatePort`, `ConfigPort`, or `EventPort`, never into a module global or `app.state` (exit criterion 8; `pocs/poc-04-stateless-scalable/notes/2026-10-01-hidden-state.md`).
- `valkey`, `aiokafka`, and `minio` are imported only under `adapters/`, inside a lazy factory; never in `core` or `ports`.
- A new `spec.*` field is restart-only unless it is added to `RELOADABLE` and read per request from `state.config`. A reload never changes a run that is already open.
- Idempotency applies only to a key the client sent. Only a run that ended with `end` is cached; a keyed call fails closed with 503 `state_unavailable` when the store fails (suggested).
- Shutdown order is fixed: `/ready` 503, the drain delay, the public listener, in-flight runs, pending result events, the ports, then the proxy listener last. Signals belong to `lifecycle`, never to uvicorn.
- Result events never change a response and are never awaited by the request.

## Test

`make test` or `uv run pytest packages/chassis`. Contract bindings live in `tests/test_contracts.py` (ports) and `tests/test_inbound_contract.py` (`InboundAdapterContract`, three times). The interface matrix is in `pocs/poc-03-one-interface-every-client/tests/`. PoC-4 bindings are files of their own: `tests/test_state_contract.py` (`InMemoryState`), `tests/test_events_contract.py` (`InMemoryBus`); unit tests in `test_idempotency.py`, `test_idempotency_serve.py`, `test_client_disconnect.py`, `test_config_loader.py`, `test_readiness.py`, `test_shutdown.py`, `test_result_events.py`, `test_dapr_inbound.py`, `test_events.py`. Real adapters (Valkey, MinIO, Kafka, Dapr) bind the same suites in `tests/integration/`, all marked `network`, run by `make test-integration` (Docker, testcontainers; skipped when Docker is not reachable; never in the gate). The PoC-4 scenarios are in `pocs/poc-04-stateless-scalable/tests/`.

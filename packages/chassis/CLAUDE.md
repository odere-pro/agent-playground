# packages/chassis

The service chassis. Day 0 holds the contract and the fakes; the walking skeleton adds the server.

## Layout

- `core/` envelope (`Request`, `Response`, `Context`, `TaskInput`, `Versions`), events (`Start`, `Delta`, `ToolCall`, `Metrics`, `End`, `Error`), `collect()`, the `Handle` type and `echo`. No network, no product SDK. `make lint` enforces it.
- `ports/` one `typing.Protocol` per dependency: `ModelPort`, `EngineConnector`, `ConfigPort`, `TelemetryPort`, bundled in `PortBundle`. New ports arrive with their first adapter (see `profiles.REGISTRY` for which PoC).
- `fakes/` in-memory doubles: `ScriptedModel`, `FakeEngine`, `InMemoryConfig`, `InMemoryTelemetry`. `FakeEngine` is a test double, not a lane.
- `adapters/` real adapters, one package per product; the product SDK is imported only there. `litellm/` is `LiteLLMModel`: `ModelPort` over OpenAI-compatible HTTP with httpx, built by `LiteLLMModel.from_env()` from `LITELLM_BASE_URL` and `LITELLM_API_KEY`; the key is never logged. It binds the same contract suite as `ScriptedModel` in `tests/test_contracts.py`, offline, against the fake model server. `a2a/` is the A2A lane (a2a-sdk 1.2, imported only here): `mapping.py` (events to A2A updates and back, pure, no chassis import), `server.py` (`HandleExecutor`, `build_agent_card`, `build_app`: the template server around a wire-form `handle`), `inprocess.py` (`InProcessConnector`: that server in this process over `httpx.ASGITransport`). Spec: `docs/contracts/contract-v0.md`, "Chassis events over A2A".
- `server/` `config.py` (`ChassisConfig`, `load_config`), `app.py` (`/health`, `/ready`, `/v1/run`), `model_proxy.py` (`POST /v1/chat/completions`: the OpenAI-compatible pass-through a workload calls, mapped onto `ports.model`; never forwards `Authorization`), `cli.py` (`chassis serve`).
- `profiles.py` `spec.adapters`, the `fake`/`local`/`cloud` profiles, `build_ports`, `check_lane`. `engine: inprocess` builds `InProcessConnector`; `spec.engine.handle` names the workload as `module:attribute`.
- `configs/` `fake.yaml` (the simplifier `echo_python:handle` in the `inprocess` lane, scripted model) and `local.yaml`.
- `schemas.py` and `schemas/*.json` the published JSON Schemas, generated by `make schemas`; a test fails on drift.

## Rules

- A change to an event or envelope field is a contract change: ask `chassis-architect`, bump `schema_version` on a breaking change, keep the previous major accepted, run `make schemas`.
- Every new port gets a fake and a suite in `packages/contract-suites` in the same change (skill `contract-suite`).
- `inprocess` is for the chassis's own tests and local runs. `check_lane` refuses it elsewhere.

## Test

`make test` or `uv run pytest packages/chassis`. Contract bindings live in `tests/test_contracts.py`.
